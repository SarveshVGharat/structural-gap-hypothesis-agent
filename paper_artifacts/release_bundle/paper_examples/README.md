# Curated Paper Examples

This directory is a public-facing index of sanitized examples from the actual SGHA paper runs.

- `main_sgha/` contains SGHA examples used for the method/evidence-graph discussion, the Bandits qualitative example, and a five-domain representative summary.
- `baselines/` contains sanitized qualitative examples from AI-Scientist-v2 Qwen, AI-Scientist-v2 Claude Opus, and MOOSE-Star baseline outputs.
- `profile_conditioned/` contains a profile-conditioned example and its paper-ready score context.
- `evolutionary/` contains the selected evolutionary exploration example.

The generated candidate text is preserved where possible. Raw PDFs, parsed full texts, raw prompts, raw model responses, caches, logs, private paths, and secret values are excluded.
