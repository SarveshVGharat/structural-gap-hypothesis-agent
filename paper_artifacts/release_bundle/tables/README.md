# Tables

This directory is intentionally minimal. The public bundle carries canonical section-level table artifacts rather than a broad export of CSV, LaTeX, and Markdown copies.

Use the canonical paper-facing table locations instead:

- `main_results/` for the main pipeline, formulation-quality, structural-coverage, and qualitative-example CSVs.
- `profile_conditioned/` for profile-conditioned pipeline, score, and profile summary tables.
- `evolutionary/scores/` for evolutionary formulation-score aggregates.
- `sensitivity/model_size/` and `sensitivity/corpus_size/` for model-size and corpus-size sensitivity tables.
- `judge_scores/main_comparison/` for retained main-comparison score aggregates and judging rubric material.

Broad non-paper table exports are excluded from the public artifact bundle.
