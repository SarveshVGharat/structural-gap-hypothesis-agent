# Main Paper Result CSVs

This directory collects the key result CSVs in one place for readers who want the main paper numbers without navigating the full artifact tree.

- `pipeline_yield.csv` mirrors `tables/csv/table_1_sgha_pipeline_yield.csv`.
- `formulation_quality_scores.csv` mirrors `tables/csv/table_2_formulation_quality_main.csv`.
- `structural_artifact_coverage.csv` mirrors `tables/csv/table_3_structural_artifacts.csv`.
- `qualitative_example_overview.csv` indexes the curated examples under `paper_examples/` and records the score source for each.

These files are derived from existing sanitized paper artifacts. They contain scores, generated titles, and source IDs, but no raw papers, parsed full texts, private paths, raw prompts, raw model responses, logs, or caches.
