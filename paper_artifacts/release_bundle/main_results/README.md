# Main Paper Result CSVs

This directory contains the canonical public CSVs for the main paper results.

- `pipeline_yield.csv`: main SGHA pipeline yield table.
- `formulation_quality_scores.csv`: main formulation-quality comparison table.
- `structural_artifact_coverage.csv`: structural artifact coverage table.
- `qualitative_example_overview.csv`: index of curated examples under `paper_examples/` with score/source pointers.

These files are derived from existing sanitized paper artifacts. They contain scores, generated titles, and source IDs, but no raw papers, parsed full texts, private paths, raw prompts, raw model responses, logs, or caches.
